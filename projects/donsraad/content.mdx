Automate Landsraad mission picking with ease.

Donsraad is an Easy Mission Picker for [Dune: Awakening](https://duneawakening.com/), a game I love. It is a personal learning project and a portfolio piece. It is **not** intended for general use.

Choose up to three repeatable targets. Auto mode claims rewards, re-rolls the board, and accepts those missions again when a run finishes. When missions are completed, app will detect it and claim rewards then run the cycle again until all targetted missions are accepted again!

Windows 10 or 11. Download the portable build, unzip, and run `Donsraad.exe`.

## How to use

1. **Settings** — Enter your character, guild name, and faction. Guild name is required to refresh the board. Turn on **AutoRun** if you want the next pick loop to start automatically.
2. **Pick your missions** — The mission board matches the in-game Landsraad house grid. Click the same house cell you use in game, then choose the mission you want from that spot. You can pick up to three targets — one specialization per cell.
3. **Initialize and pick** — Press **Initialize** or the Start keybind (<kbd>Home</kbd>). This gets the app ready for your session. Press **Start** again to run the mission pickup loop. When all your targeted missions are accepted, your run begins!
4. **Play and repeat** — Run your missions in game. With AutoRun on, finish a run so **View mission report?** appears, or leave the **Travel confirmation** at the ornithopter open — either one starts the next loop. Press **End** to stop the picker, or <kbd>Delete</kbd> to toggle AutoRun.

Press <kbd>F8</kbd> or use the tray icon to show or hide the dashboard. <kbd>Insert</kbd> toggles the status bar. All keys can be changed in **Settings**.

## Features

- **House grid picker** — The mission board mirrors the in-game Landsraad house grid. Pick the same cell and mission you want in game, up to three targets total.
- **AutoRun** — Claims rewards, re-rolls the board, and accepts your targets again when a run finishes.
- **Guild refresh** — Re-rolls random offers by disbanding your guild until your picks show up.
- **Profiles** — Separate settings per character: name, guild, faction, and mission picks.
- **Status bar** — Run status pinned to the game window, with session completes and target progress. Moves to the bottom left while picking so it stays out of the way.
- **Stats** — Mission completes, best times, and availability estimates.
- **Tray menu** — Control the dashboard, status bar, AutoRun, and picker from the system tray.
