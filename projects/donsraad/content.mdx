Automate Landsraad mission picking with ease.

Donsraad is an Easy Mission Picker for [Dune: Awakening](https://duneawakening.com/). Choose up to three target missions. In auto mode it completes the loop for you: claims rewards, re-rolls the board, accepts the same targets again, and notifies you — no further input.

Windows 10 or 11. Keep the game focused when a pass is running. Download the portable build, unzip, and run `Donsraad.exe`.

## How to use

1. **Settings.** Set guild name, faction, action delay, and any other options you want. Guild name is required to refresh the board. Add profiles if you play more than one character.
2. **Targets.** On Mission Picker, choose up to three missions. One specialization per house cell, matching what that house actually offers.
3. **Initialize.** Focus Dune: Awakening, then press **Initialize** or the Start hotkey (<kbd>Home</kbd> by default). Landsraad does not need to be open.
4. **Auto mode.** Enable AutoRun in Settings. When you reach the ornithopter and the overland Travel confirmation appears, leave that window open. Donsraad detects it, runs the loop again, and stops when the same target missions are accepted.
5. **Manual mode.** Press the Start hotkey and wait for the loop to finish. Press it again when you want the next batch.

Hide the dashboard with the window **X** or <kbd>Delete</kbd>. Toggle the overlay with <kbd>Insert</kbd>. <kbd>Pause</kbd> exits. All four keys are rebindable.

## Features

- **Target picker** — Up to three repeatable Landsraad missions on the house grid. Green cells are your targets. A wrong specialization on a cell stops the run so it cannot loop forever.
- **AutoRun** — After targets are accepted, Donsraad claims completed missions, re-rolls until those targets are back, and notifies you. Overlay **AUTO** is green when this is on, gray when it is off.
- **Manual runs** — One hotkey starts a pass. Press Start again while a loop is running to cancel and return to Ready.
- **Guild refresh** — Re-rolls offers by disbanding and recreating the guild, then aligning it to your faction.
- **Profiles** — Separate character name, guild, faction, and mission picks per alt. Settings save automatically.
- **Action delay** — Slow down or speed up automation to match the client.
- **Overlay** — Always-on HUD for status, current run, targets, mnemonic devices, and profile. Target count turns green when all targets are active. Pin it to top left, bottom left, top middle, top right, or bottom right. Toggle it with <kbd>Insert</kbd>, or hide individual blocks in Settings. Optional notifications for “Ready to run missions!” and a new best time.
- **Mnemonic devices** — Overlay shows remaining tokens after initialize (for example `7/35`). Each claim subtracts one. Stats tracks tokens spent.
- **Stats** — Per-mission completes and best times by specialization, plus session abandons and targeted accepts. Reset stats independently of Settings.
- **Keybinds** — Rebind Start (<kbd>Home</kbd>), dashboard (<kbd>Delete</kbd>), overlay (<kbd>Insert</kbd>), and exit (<kbd>Pause</kbd>). Click a bind, press a key, <kbd>Esc</kbd> cancels.
- **Resolution** — Built for 3440×1440. Other sizes are scaled in software; see Beta below.

## Beta

Donsraad is a beta. It was built on an ultrawide **3440×1440** display. Other resolutions are scaled, but they have not been tested yet.
