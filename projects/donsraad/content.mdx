Automate Landsraad mission picking with ease.

Donsraad is an Easy Mission Picker for [Dune: Awakening](https://duneawakening.com/), a game I love. It is a personal learning project and a portfolio piece. It is **not** intended for general use.

Choose up to three repeatable targets. Auto mode claims rewards, re-rolls the board, and accepts those missions again when a run finishes. When missions are completed, app will detect it and claim rewards then run the cycle again until all targetted missions are accepted again!

Windows 10 or 11. Keep the game focused when a pass is running. Download the portable build, unzip, and run `Donsraad.exe`.

## How to use

1. **Settings.** Set guild name, faction, action delay, and AutoRun if you want it. Guild name is required to refresh the board. Add profiles if you play more than one character.
2. **Targets.** On Mission Picker, choose up to three missions. One specialization per house cell, matching what that house actually offers. Green cells are your targets.
3. **Initialize.** Focus Dune: Awakening, then press **Initialize** or the Start hotkey (<kbd>Home</kbd> by default). Landsraad does not need to be open.
4. **Auto mode.** Enable AutoRun in Settings. After your targets are accepted, Donsraad starts the next loop when it sees the in-world **View mission report?** prompt, or the **Travel confirmation** at the ornithopter. For Travel, leave that popup open — do not confirm it yet. After a ready state, mission-report detection waits **30 seconds** so a leftover or mid-mission report does not start another loop. Overlay **AUTO** is green when this is on.
5. **Manual mode.** Press the Start hotkey and wait for the loop to finish. Press it again when you want the next batch, or press it during a run to cancel.

Hide the dashboard with the window **X**, <kbd>Delete</kbd>, or the tray icon. Toggle the overlay with <kbd>Insert</kbd> or the tray. <kbd>Pause</kbd> exits. Keys are rebindable.

## Features

- **Target picker** — Up to three repeatable Landsraad missions on the house grid. A wrong specialization on a cell stops the run so it cannot loop forever.
- **AutoRun** — Claims completed missions, re-rolls until your targets are back, and notifies you. Detects a finished run from the mission-report prompt or the Travel window. Overlay **AUTO** is green when this is on.
- **Manual runs** — One hotkey starts a pass. Press Start again while a loop is running to cancel.
- **Guild refresh** — Re-rolls offers by disbanding and recreating the guild, then aligning it to your faction.
- **Profiles** — Separate character name, guild, faction, and mission picks per alt. Settings save automatically and survive extracting an update over the same folder.
- **Action delay** — Slow down or speed up the picker in Settings to match the client.
- **Overlay** — Status, run, targets, mnemonic devices, and profile. Pin it to a corner (top middle is not available). Target count turns green when all targets are active. Ready notices can include abandons that cycle and a new best time.
- **Mnemonic devices** — Overlay shows remaining tokens after initialize, including two-digit counts such as `11/35`. Stats tracks tokens spent.
- **Stats** — Completes, best times, session totals, and **Availability** (how often a mission shows, only when you target exactly one mission from that specialization). Reset stats without wiping settings.
- **Tray** — Left-click shows the dashboard. Right-click can show overlay, toggle AutoRun, start or stop the picker, and exit.
- **Keybinds** — Rebind Start (<kbd>Home</kbd>), dashboard (<kbd>Delete</kbd>), overlay (<kbd>Insert</kbd>), and exit (<kbd>Pause</kbd>). Click a bind, press a key, <kbd>Esc</kbd> cancels.
- **Resolution** — Built for 3440×1440. Other sizes are scaled in software; see Beta below.
